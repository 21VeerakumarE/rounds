# Rounds

A daily clinical reasoning case for med students: work up the patient against the clock (ask anything, order tests, call for help at a price) and name the diagnosis.

Play: https://21veerakumare.github.io/rounds/

Rounds is a study game for medical students. Cases are simplified teaching scenarios, not medical advice. Content is still being checked.

This repository holds only the built site for GitHub Pages. Source is private.
